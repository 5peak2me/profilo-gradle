# Profilo-Gradle: an Android performance library

## Introduction
Profilo is an Android library for collecting performance *traces* from production builds of an app.
> This is Gradle Version of [profilo](https://github.com/facebookincubator/profilo)

- based on [5a66b93](https://github.com/facebookarchive/profilo/commit/5a66b9372c137be036403d9c6f89a57ce4111d0a)
- the artifacts in the [dist](dist) dir based on [release-5a66b93](https://github.com/facebookarchive/profilo/releases/tag/release-5a66b937)
- all dynamic libraries in profilo module's [jniLibs](profilo/src/main/jniLibs) dir unziped from the [aar](dist/profilo.aar) of  [release-5a66b937](https://github.com/facebookarchive/profilo/releases/tag/release-5a66b937)
